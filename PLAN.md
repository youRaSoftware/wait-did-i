## Что это за проект

Мобильное приложение-помощник памяти. Решает бытовую забывчивость:
человек выходит из дома и не помнит — запер ли дверь, выключил ли
плиту, закрыл ли окна. Приложение позволяет за пару секунд отметить
пункт чек-листа и при желании сделать фото-подтверждение, чтобы
спокойно идти дальше.

- **Платформа:** Flutter (Android + iOS).
- **Display name (на иконке, `CFBundleDisplayName`):** `Wait, Did I?` (DEV/STAGE-сборки — с суффиксом окружения).
- **App Store listing name:** `Wait, Did I Lock It?` — имя `Wait, Did I?` в сторе было занято, поэтому в листинге уникальное название; на иконке остаётся короткое `Wait, Did I?`.
- **Bundle id / package:** `com.pyf.waitdidi` (prod), `com.pyf.waitdidi.stage`, `com.pyf.waitdidi.dev`.
- **App Store subtitle:** `Home Checklist`.

## Позиционирование — важно для всех решений

Приложение позиционируется как **утилита от забывчивости (memory aid)**,
а НЕ как «лечение тревоги» или медицинский продукт.

Тема граничит с симптомами ОКР (навязчивые перепроверки). Поэтому есть
жёсткие продуктовые ограничения — их нельзя нарушать «ради вовлечённости»:

- НЕ добавлять «Peace of Mind Score», проценты спокойствия, оценки.
- НЕ добавлять стрики, геймификацию, бейджи, «не разорви цепь».
- НЕ поощрять повторный просмотр старых фото (никакой галереи для
  пересматривания, никакого OCR по фото).
- НЕ использовать слова «anxiety» / «OCD» в UI, текстах, описании стора.
- НЕ использовать красный цвет и тревожные сигналы. Максимум «тревоги» —
  мягкий жёлтый «стоит проверить».
- Фото — одноразовое подтверждение, а не предмет для перепроверок. В UI
  явно сообщать: одного снимка достаточно.

Цель — пользователь глянул один раз и успокоился, а не залипает в
приложении. Меньше вовлечённости здесь = лучше для пользователя.

## Тон голоса

Разговорный, человечный, с лёгким выдохом облегчения (его задаёт само
название). Не «Verification complete» → а «Готово, дверь отмечена».
Не «2 pending items» → а «Осталось глянуть 2 пункта».

Конкретные фразы (для согласованности по всему приложению):

- Greetings (меняются по времени суток): `Good morning`, `Hey there`,
  `Good evening`, `Wind down`, `Heading out?`, `All clear`, `Wait, Did I?`.
- Подсказки прогресса: `Good start`, `Almost there`, `One more to go.`,
  `All done`, `Have a good evening.`.
- Пункты по умолчанию: `Front door`, `Stove off`, `Windows closed`.

## Дизайн-система

**Тёмная тема — основная и по умолчанию** (онбординг тёмный → главный экран
тоже тёмный, переход бесшовный). Светлая — опцией в настройках (позже),
в скоуп MVP не входит. Источник истины по цветам — `light.json` / `dark.json`
(токены `LightTokens` / `DarkTokens`).

### Цвета

- **Dark (основная):** фон `#0F1419` / `#1A202C` / поверхности `#1E2530`;
  текст `#F7FAFC` / `#B4C0CE` / `#718096`; бренд `#5A9BD4` (акцент),
  градиент `#7BB0DD → #4F86C6`; success `#68C58F`, warning `#E8B860`.
- **Light (позже, опцией):** фон `#F4F7F9`, карточка `#FFFFFF`, акцент `#5A9BD4`,
  текст `#2D3748` / `#718096`.
- **Без красного.** Максимум «тревоги» — мягкий жёлтый warning.

### Шрифт

Manrope, веса 400 / 500 / 600 / 700. (Display-шрифт Playfair Display забандлен,
но в продуктовых экранах используется Manrope.)

### Форма и анимации

- Скругления крупные: small 8 / medium 12 / large 16 / xlarge 24 (карточки ~14).
- Тени минимальные — вместо них тонкие бордеры с opacity (~0.5px).
- Иконки: один контурный набор одной толщины (Material outlined / tabler /
  lucide). Не смешивать контурные и заливочные.
- Кривые анимаций:
  - `easeOutBack` (cubic-bezier 0.34, 1.56, 0.64, 1) — падения, отскоки, штампы.
    **Главная** кривая характера приложения.
  - `easeOutCubic` (cubic-bezier 0.22, 1, 0.36, 1) — текст, фейды, переходы.
- Микроанимация отметки: короткая (~300–400 мс), мягкая. Без конфетти.
- Haptic на тапы по чекбоксам — `HapticFeedback.lightImpact()`.
- Состояния пункта чек-листа — три, читаются без подписи: зелёный кружок с
  галочкой (отмечено), пунктирный пустой кружок (ещё нет), жёлтый с колокольчиком
  (стоит проверить). Красного состояния нет.

### Иконка приложения

Фирменный знак — **силуэт ключа в форме знака вопроса** на голубом градиенте
`#7BB0DD → #4F86C6`. Используется в иконке приложения и в push-уведомлениях.

### Маскот

Дружелюбный домик-маскот **«Дотти»** с разными выражениями лица. Используется
в маркетинге, на лендинге, в пустых состояниях экранов (но НЕ в иконке).

## Скоуп

### MVP 1.0 (текущая цель)

- **Онбординг — ✅ дизайн готов, реализован.** Спека: `.claude/specs/onboarding/`.
- **Главный экран — ✅ дизайн готов.** Спека: `.claude/specs/home/`. Модель навигации —
  текущий список сразу на главном, переключение между списками через табы.
- После онбординга **автоматически создаётся** один дефолтный список `Leaving home`
  с пунктами `Front door`, `Stove off`, `Windows closed` — пользователь сразу видит
  контент, а не пустой экран.
- Экран отметки пункта: два пути — «сделать фото» и «просто отметить». Оба ставят
  таймстемп. (в разработке)
- Локальное хранение всего (списки, отметки, фото). Без облака.
- Фото авто-удаляются через 30 дней.
- История проверок — простой список «что и когда», без оценок.
- Одно напоминание по времени.
- Блокировка приложения по Face ID / passcode.
- Тёмная тема по умолчанию; светлая — опцией в настройках (позже).
- Монетизации в 1.0 НЕТ.

### 1.1–1.2 (после)
- Геозона: напоминание при выходе из дома (фоновый geofencing). Вынесено из 1.0
  намеренно — технически капризно, ест батарею.
- Несколько локаций, заметки к проверкам.
- Недельная сводка фактов (без «score»).
- Premium-стена: безлимит списков, геозона, бэкап.

### 2.0+
- Семейный доступ (удалённая проверка для пожилого родителя).
- Облачный бэкап, больше шаблонов.

### Вне скоупа полностью
- Псевдо-AI «определение паттернов тревоги», предиктивные алерты.
- Любая геймификация и оценочные метрики (см. «Позиционирование»).

## Технический стек (предполагаемый)

- Flutter 3.x (Dart workspaces; FVM не используется — несовместим с workspace).
- Локальное хранилище: Hive + flutter_secure_storage (для шифрования).
- Камера: camera / image_picker.
- Уведомления: flutter_local_notifications + timezone.
- Геозона (с 1.1): geolocator + geofence_service + google_maps_flutter.
- Состояние: flutter_bloc (Cubit), как в текущем каркасе.
- Календарь в истории: table_calendar.

Стек не догма — если есть более простое решение под конкретную задачу, предлагай.

## Принципы при работе над кодом

- MVP-минимализм: не строить впрок. Если фича не в скоупе 1.0 — не делать.
- Приватность по умолчанию: данные не покидают устройство. Любой код,
  отправляющий данные наружу, требует явного обсуждения.
- Стандартные компоненты Flutter везде, где можно (Switch, TextField,
  bottom sheet). Кастомить только то, что несёт характер приложения.
- Перед тем как добавить что-то, что повышает вовлечённость, — свериться
  с разделом «Позиционирование». Для этого продукта это антипаттерн.
