# Feature design specs

Durable дизайн-спеки фич приложения «Wait, Did I?». Один подкаталог на фичу.

## Структура

```
.claude/specs/<feature>/
├── spec.md          # детальная спека реализации (Flutter)
└── reference.html   # рабочий эталон-прототип (открыть в браузере)
```

Сейчас: `onboarding/`, `home/`.

## Правила

- **При расхождении кода и `reference.html` — эталон прав.** CSS-числа в нём
  финальные, выверены глазом (тайминги, цвета, углы, тени).
- `spec.md` пишется под архитектуру проекта (cubit/screen/form, go_router,
  токены/виджеты — см. `.claude/shared/ui_reference.md`). Если спека пришла в
  «ванильном» Flutter-стиле — визуал берём из эталона, архитектуру из проекта.
- Новая фича с дизайном → новый подкаталог `specs/<feature>/` (`spec.md` +
  `reference.html`). **Не** плодить файлы в корне репозитория.

## Куда что

- **Продуктовый контекст** (позиционирование, тон, дизайн-система, скоуп) — в
  корневом `PLAN.md` (единый источник правды). Не заводить `CLAUDE_2/3.md` и
  прочие версионные дампы — обновлять `PLAN.md`.
- **Инструкции для Claude Code** (команды, архитектура, workflow) — `CLAUDE.md`.
- **Лог изменений по файлам** — `CLAUDE_CHANGES.md`.
